# 🌐 3D Website — "Email For Developers"

A sleek, modern landing page with a 3D feel, built with HTML, CSS, [Spline](https://spline.design), and the [AOS](https://michalsnik.github.io/aos/) (Animate On Scroll) library. It features a gradient background layer, blur effects, and beautifully choreographed entrance animations for every section.

## ✨ Features

- 🧊 **3D scene** powered by Spline, embedded in the page
- ✨ **Scroll-triggered animations** via AOS — fade-down, fade-zoom-in, staggered durations
- 🌈 Gradient image layer with a blur overlay for depth
- 🧭 Animated header with logo, nav links (Company, Features, Resources, Docs) and a sign-in button
- 🦸 Hero section: "Email For Developers" headline, tag box, and description

## 🛠️ Tech Stack

- HTML5
- CSS3
- [Spline](https://spline.design) — interactive 3D content
- [AOS](https://michalsnik.github.io/aos/) — Animate On Scroll library (CDN)

## 📂 Project Structure

```
3D-WEBSITE/
├── index.html          # Page markup + AOS animation attributes
├── main.css            # Layout, gradient & blur styles
└── images/
    └── gradient.png    # Gradient background layer
```

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/shena9y/3D-WEBSITE.git
   ```
2. Open `index.html` in your browser — the AOS library loads from a CDN, so an internet connection is needed for the animations.
